## ADR Template

```text
# ADR-XXX — Title

## Status
Proposed | Accepted | Superseded | Deprecated

## Context
What problem or constraint led to this decision?

## Decision
What was decided?

## Alternatives
What other options were considered?

## Consequences
What are the trade-offs and follow-up effects?
```
