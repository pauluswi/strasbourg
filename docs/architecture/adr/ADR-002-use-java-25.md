# ADR-002 — Use Java 25

## Status
Accepted

## Context
The platform aims to showcase modern Java capabilities for a production-inspired financial services system.

## Decision
Use Java 25 as the primary language level.

## Alternatives
- Java 21
- Java 17

## Consequences
- Access to modern language features
- Aligns with the architecture goal of a modern Java showcase
- Requires tooling and build compatibility with Java 25
